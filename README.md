## 주행 모터

| 위치 | 포트 | 방향 반전 | 카트리지 |
|---|---|---|---|
| 왼쪽 앞 | 1 | True | 초록 18:1 |
| 왼쪽 뒤 | 3 | True | 초록 18:1 |
| 오른쪽 앞 | 2 | False | 초록 18:1 |
| 오른쪽 뒤 | 4 | False | 초록 18:1 |

옴니휠을 45도로 배치한 X-drive 기준
왼쪽 True와 오른쪽 False는 임시 설정이며, 장착 후 낮은 속도로 전후와 좌우 이동 및 회전 방향을 확인해야 한다
모터 방향이나 바퀴 장착 각도가 다르면 반전 설정과 속도 계산의 부호를 맞춰야 한다

## 컨트롤러

| 입력 | 기능 |
|---|---|
| 왼쪽 스틱 상하 (`axis3`) | 전진/후진 |
| 왼쪽 스틱 좌우 (`axis4`) | 좌우 평행이동 |
| 오른쪽 스틱 좌우 (`axis1`) | 좌우 회전 |
| 위/아래 버튼 | 할당 없음 |
| L2 / L1 | 리프트 상승 / 하강 |
| R1 / R2 | 집게 열기 / 닫기 |
| A | 리프트 아래쪽 기준 위치를 0도로 등록 |
| X | 집게 닫힘 기준 위치를 -59도로 등록 |
| 왼쪽/오른쪽 버튼 | 집게 회전용 입력, 현재 모터 미설정으로 비활성화 |

최고속도는 100%, 데드존은 0으로 작은 입력도 그대로 반영한다
각 스틱 입력은 부호를 유지한 제곱 계산을 적용해 중앙 부근에서 섬세하게 움직이며, 끝까지 밀면 최대 입력이 된다
입력 조합이 최대값을 넘으면 네 바퀴를 같은 비율로 줄인다
`PERCENT`는 모터 속도 명령 단위이며, 소비 전력 비율이나 정확한 지면 속도를 뜻하지 않는다

주행 모터의 최대 토크는 100%, 정지 방식은 HOLD
입력 계산 결과가 0일 때 stop을 호출해 위치를 유지하려고 힘을 준다
데드존이 0이라 스틱을 놓아도 값이 남으면 정지하지 않을 수 있다
HOLD도 관성에 의한 이동을 완전히 없애거나 전원 없이 위치를 유지하지는 못한다
출발 가속을 제한하는 기능은 없으며, 실제 로봇에서 급정지 충격과 발열을 확인해야 한다

## 리프트·집게 설정

`main.py`에서 다음 설정을 실제 기구에 맞춰 수정해야 한다

- `LIFT_PORT_1`, `LIFT_PORT_2`, `CLAW_PORT`, `WRIST_PORT`: 리프트 6번과 7번, 집게 5번, 회전축은 `None`.
- 각 `GEARS`, `REVERSED`: 리프트 빨강 36:1과 왼쪽 False 오른쪽 True, 집게 초록 18:1과 False는 실제 기구 확인 필요.
- `LIFT_LOWER_LIMIT`, `LIFT_UPPER_LIMIT`: 아래쪽 0도와 위쪽 -1400도.
- `CLAW_CLOSED_LIMIT`, `CLAW_OPEN_LIMIT`: 닫힘 -59도와 열림 -388도.
- 각 `SPEED`, `TORQUE`: 리프트 100%와 100%, 집게 40%와 30%.
- 각 `ENABLED`: 리프트와 집게는 `True`, 회전축은 `False`.

실제 기준 위치에 맞춘 뒤 리프트는 A와 집게는 X로 등록해야 조작할 수 있다
영점 버튼은 현재 위치에 각도값을 붙일 뿐, 실제 원점을 찾아 움직이지 않는다
리프트는 상승할수록 두 모터 각도가 감소하며, 집게는 열릴수록 각도가 감소한다
리프트 두 모터 중 하나라도 이동 한계에 닿으면 둘 다 멈추지만, 두 모터의 위치 차이를 자동 보정하지 않는다
기구 변경 후에는 이동 한계와 기준 위치를 다시 측정해야 하며, 현재 수치는 안전을 보장하지 않는다

대회용 자율주행과 경기장 제어 전환은 아직 구현하지 않았다
