# VEX 프로젝트

VEX V5 로봇을 Python으로 조종하는 프로젝트입니다. 4륜 주행과 리프트, 집게 여닫기 및 회전을 제어합니다.

## 현재 상태

대화에서 작성한 기본 코드를 정리한 초안입니다. 실제 VEXcode 프로젝트에서 추출한 파일은 아니며, 로봇에서 통합 시험하지 않았습니다. 주행 설정은 사용자가 확인한 포트와 방향을 반영했습니다. 추가 기구는 포트와 이동 범위를 확인하기 전까지 비활성화되어 있습니다.

## 주행 모터

| 위치 | 포트 | 방향 반전 | 카트리지 |
|---|---|---|---|
| 왼쪽 앞 | 1 | True | 초록 18:1 |
| 왼쪽 뒤 | 2 | True | 초록 18:1 |
| 오른쪽 앞 | 3 | False | 초록 18:1 |
| 오른쪽 뒤 | 4 | False | 초록 18:1 |

## 컨트롤러

| 입력 | 기능 |
|---|---|
| 왼쪽 스틱 상하 (`axis3`) | 전진/후진 |
| 오른쪽 스틱 좌우 (`axis1`) | 좌우 회전 |
| 위/아래 버튼 | 주행 최고속도 ±10%, 범위 20~100% |
| L2 / L1 | 리프트 상승 / 하강 |
| R1 / R2 | 집게 열기 / 닫기 |
| 왼쪽/오른쪽 버튼 | 집게 위/아래 회전 |

시작 최고속도는 50%, 데드존은 5입니다. 조이스틱을 더 조금 움직이면 명령 속도도 작아집니다. `PERCENT`는 모터 속도 명령 단위이며, 소비 전력 비율이나 정확한 지면 속도를 뜻하지 않습니다.

## 실행 방법

1. VEXcode V5에서 새 Python 텍스트 프로젝트를 만듭니다.
2. 편집 가능한 기존 코드를 `main.py` 내용으로 교체합니다. 이 파일은 Brain과 모터를 직접 생성하므로 Devices 메뉴에서 동일 포트의 모터나 자동 주행 코드를 중복 설정하지 않습니다.
3. Brain에 다운로드합니다. 바퀴를 띄워 포트와 방향을 먼저 확인한 뒤 주행합니다.
4. VEXcode의 저장 기능으로 `.v5python` 파일도 저장합니다. 현재 저장소에는 원본 `.v5python` 파일이 아직 없습니다.

PC에서 일반 Python으로 실행하는 프로그램은 아닙니다. `vex` 모듈은 VEX 실행 환경에서 제공됩니다.

## 리프트·집게 설정

`main.py`에서 다음 설정을 실제 기구에 맞춰 수정해야 합니다.

- `LIFT_PORT_1`, `LIFT_PORT_2`, `CLAW_PORT`, `WRIST_PORT`: 실제 Smart Port. 기본값은 `None`.
- 각 `GEARS`, `REVERSED`: 실제 카트리지와 동작 방향.
- 각 `MAX_DEG`: 모터 축 기준 최대 이동 각도. 기계적 끝보다 여유 있게 설정.
- 각 `SPEED`, `TORQUE`: 기구에 맞는 속도와 최대 토크.
- 각 `ENABLED`: 설정을 완료한 기구만 `True`로 변경.

각 기구는 양수 방향으로 상승/열림/위쪽 회전하고, 이때 위치값도 증가해야 합니다. 리프트 두 모터는 같은 방향 설정을 사용한다는 조건입니다. 링크와 기어비도 같아야 하며, 현재 코드는 두 모터의 위치 차이를 자동 보정하지 않습니다.

## 기준 위치와 기어 보호

실행 전에 리프트는 아래쪽, 집게는 닫힘, 회전축은 아래쪽의 정해둔 기준 위치에 둡니다. 프로그램은 그 위치를 0도로 기록합니다. 강제로 기계적 끝을 밀어 기준을 잡지 마세요. 기준 위치 자체도 끝에서 여유를 둡니다.

`set_position(0)`은 자동 원점 복귀가 아닙니다. 프로그램을 재시작하거나 기구 위치가 변하면 기준을 다시 맞춰야 합니다. 반복적으로 쓸 때는 리미트 스위치 등으로 원점을 확인하는 절차를 추가해야 합니다.

현재 각도 제한은 20ms 간격으로 확인하므로 관성과 정지 지연에 따른 초과 이동이 있을 수 있습니다. 물체가 집게 중간에 끼는 것은 각도 제한으로 감지하지 못합니다. 토크 제한도 기어 파손을 보장해 막지 않으며, 자동 끼임 감지와 센서 기반 원점 복귀는 아직 구현하지 않았습니다. HOLD는 전원이 꺼졌을 때 리프트를 지지하지 못합니다.
